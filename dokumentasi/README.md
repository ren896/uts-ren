# Dokumentasi Sistem Nilai Mahasiswa (UTS)

Folder ini berisi dokumentasi lengkap, penjelasan teknis kode, dan panduan presentasi untuk aplikasi **01 Sistem Nilai Mahasiswa**.

---

## Daftar Berkas Dokumentasi

1. **[01_STRUKTUR_DAN_FITUR_DASAR.md](./01_STRUKTUR_DAN_FITUR_DASAR.md)**
   - Struktur file proyek (`main.dart`, `data.dart`, `input.dart`, `fitur.dart`).
   - Aturan perhitungan nilai & bobot.
   - Penjelasan fitur bawaan (Menu 1: Tampilkan Daftar, Menu 2: Tambah Mahasiswa, Menu 3: Lihat Nilai Akhir).
   - Penjelasan fungsi-fungsi bantu (`hitungNilaiAkhir`, `hurufMutu`, `cariByNim`, `cetakMahasiswa`, `cetakNilaiAkhir`).

2. **[02_FITUR_TAMBAHAN_4_5_6.md](./02_FITUR_TAMBAHAN_4_5_6.md)**
   - Penjelasan lengkap 3 fitur tambahan yang dipilih dan dikerjakan:
     - **Menu 4 (Mudah)**: `cariMahasiswa()` — Mencari mahasiswa berdasarkan NIM.
     - **Menu 5 (Mudah)**: `tampilkanRataRata()` — Menghitung rata-rata nilai akhir kelas.
     - **Menu 6 (Sedang)**: `ubahNilai()` — Mengubah nilai tugas, UTS, dan UAS mahasiswa.
   - Rincian kode baris per baris.
   - Penanganan error / *edge case* (misalnya validasi data kosong dan NIM tidak ditemukan).
   - Status fitur lainnya (Menu 7, 8, 9, 10).

3. **[03_PANDUAN_PRESENTASI_UTS.md](./03_PANDUAN_PRESENTASI_UTS.md)**
   - Panduan langkah demi langkah untuk presentasi di **Pertemuan #8**.
   - Skrip presentasi (apa yang perlu diucapkan).
   - Data uji coba (Test Cases) untuk demonstrasi fitur di hadapan dosen/asisten.
   - Prediksi pertanyaan teknis dosen beserta kunci jawabannya.
